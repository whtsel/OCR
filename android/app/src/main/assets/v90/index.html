Windows setup guideUse this once if the phone cannot open the LAN address
  1. Connect the laptop and receiver to the same trusted Wi-Fi or phone hotspot.
  2. On Windows, open Settings → Network & internet → Wi-Fi → the current network, then set Network profile type to Private.
  3. Open Windows Security → Firewall & network protection → Allow an app through firewall → Change settings. Find blackbox-local-share.exe and tick Private. You do not need to disable the firewall or enable Public.
  4. Close BlackBox, start it again with Start BlackBox Stream.bat, turn Share on, and use the refreshed LAN address above.

Phone side: normally no hotspot-phone or iPhone setting is needed when that hotspot allows its devices to communicate. Streaming here stays on the local network and does not consume internet/mobile data. If the address still cannot open, the hotspot may isolate connected devices.

Manual address fallback

Use this only if Scan Wi-Fi cannot see the sender. You may paste the complete sender link.

Shared moviesStream now or save an explicit copy to this device.

Private boundary No cloud relay, file upload, account, UPnP, port-forwarding, browser cookies or arbitrary file paths. Receivers can access only eligible exact files explicitly shared through Local Share; files must have a cached local Microsoft Defender clean verdict. A maximum of ten receiver sessions are bound to individual Wi-Fi addresses and expire independently after four hours. Important: direct Wi-Fi links reveal the sender’s private LAN IP to paired receivers; this build does not mask it with a relay or onion address. Use only a trusted private Wi-Fi network.
